## Assignment Sections

### 1. SQL Proficiency – Hotel Management System
Queries were written to answer analytical questions such as:
- Finding the last booked room for each user
- Calculating booking billing amounts
- Identifying bills above a certain threshold
- Determining most and least ordered items per month
- Finding customers with the second highest bill value

### 2. SQL Proficiency – Clinic Management System
Queries were designed to analyze business data including:
- Revenue by sales channel
- Most valuable customers
- Monthly revenue, expense, and profit analysis
- Most profitable clinics by city
- Second least profitable clinics by state

### 3. Spreadsheet Proficiency
The spreadsheet section explains how to:
- Populate missing values using lookup functions
- Compare timestamps to determine same-day and same-hour ticket closures
- Use pivot tables to calculate outlet-wise ticket counts
